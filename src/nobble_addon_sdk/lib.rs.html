1//! Write a Nobble addon.
2//!
3//! An addon is whatever knows how to make another application do something —
4//! skip a track, switch an OBS scene, start a Fusion 360 command. You implement
5//! [`Addon`], hand it to [`run`], and the daemon does the rest.
6//!
7//! ```no_run
8//! use nobble_addon_sdk::{Addon, AddonAction, AddonError, Availability, Invocation, Trigger, run};
9//!
10//! struct Hello;
11//!
12//! const ACTIONS: &[AddonAction] = &[AddonAction {
13//!     id: "wave",
14//!     name: "Wave",
15//!     description: "Says hello.",
16//!     trigger: Trigger::Momentary,
17//!     params: &[],
18//! }];
19//!
20//! impl Addon for Hello {
21//!     fn id(&self) -> &'static str { "hello" }
22//!     fn name(&self) -> &'static str { "Hello" }
23//!     fn description(&self) -> &'static str { "An addon that waves." }
24//!     fn actions(&self) -> &'static [AddonAction] { ACTIONS }
25//!     fn availability(&self) -> Availability { Availability::Ready }
26//!     fn perform(&mut self, action: &str, _i: &Invocation<'_>) -> Result<(), AddonError> {
27//!         match action {
28//!             "wave" => Ok(()),
29//!             other => Err(AddonError::NoSuchAction(other.to_owned())),
30//!         }
31//!     }
32//! }
33//!
34//! fn main() { run(Hello); }
35//! ```
36//!
37//! # Why this is a separate process
38//!
39//! [ADR-0016](../../../docs/decisions/0016-addon-process-boundary.md). An addon
40//! runs as a child of the daemon and speaks the protocol in [`protocol`] over
41//! its stdin and stdout. That is what makes FR-045 true — a crash, a hang or a
42//! leak in your addon cannot reach input, MIDI, or anybody else's addon — and
43//! it is what lets [`Credentials`] be scoped to you rather than handed out as a
44//! key to everyone's.
45//!
46//! You do not write any of that. [`run`] owns the loop and the framing; you
47//! write the trait.
48//!
49//! # What is deliberately not here
50//!
51//! No device, input, layout or module types. An addon contributes actions,
52//! signals, settings and configuration UI (FR-047) and has no business knowing
53//! what an `InputId` is. If you find yourself needing one, that is a gap in
54//! this SDK to be reported rather than routed around — FR-050 says official
55//! addons get no private interfaces either, so the gap is real for everyone.
56
